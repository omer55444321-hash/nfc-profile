# NFC Digital Profile

قالب صفحة NFC شخصية شبيه بالتصميم المطلوب.

## التعديل
افتح `index.html` وغيّر:
- الاسم
- الوصف
- روابط WhatsApp / Instagram / TikTok / Facebook / Website / Maps
- صور `profile.jpg` و `work-1.jpg` إلى `work-4.jpg`

## النشر
ارفع الملفات إلى GitHub Repository عام، ثم فعّل GitHub Pages من:
Settings → Pages → Deploy from a branch → main → / (root)

بعد النشر، استخدم رابط الصفحة داخل شريحة NFC.
